# data/raw

Place the original, unmodified SEBI Investor Survey 2025 data files here (e.g. the source Excel/CSV workbook downloaded from SEBI).

- Do not edit these files in place.
- These files are not committed to Git (see `.gitignore`) — this folder is kept via this README so the expected location is documented.
- See [`docs/data_sources.md`](../../docs/data_sources.md) for the official source link.
