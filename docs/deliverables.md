# Deliverables

The five items this project is being assessed against. Mirrors the `/deliverables` page in the dashboard (`src/app/deliverables/page.tsx`) — the two are meant to stay in sync; if one changes, update the other.

## 1. Business problem statement

INDmoney faces a problem where salaried young adults aged 22–26 (early-career users) consider starting a mutual-fund SIP but do not complete their first SIP.

## 2–3. Industry KPIs and Marketing metrics

Groups 1–6 (industry KPIs) cover how the segment behaves. Groups 7–9 (marketing-relevant metrics) cover how to reach and persuade it. Note: groups 7–9 aren't marketing metrics in the standard sense (CAC, conversion rate, ROI) — we have no data on actual marketing activity.

The live page shows this same mapping two ways — a table (below) and a toggle-able interactive map (an expandable, searchable mind map — the same one used on the Research Plan page's Key Research Indicators section, here scoped to all 9 groups instead of just the 6 KPI ones). Both link straight to that group's or question's chart on the Analysis page; this markdown file only has the table, so it's the reference copy for this content, not the map.
